# EuroGro Retail Group - Financial Model & Data Analysis

**Tools:** Microsoft Excel
**Completed:** May 2025

## Project Overview
End-to-end financial and data analysis project for a European retail group, combining revenue modelling, scenario planning, and operational data analysis across a 2-year forecast horizon.

## What I Did
- Built a monthly revenue model across base, optimistic, and pessimistic scenarios for a 5,000-customer retail operation, projecting EUR 75,000/month at base case
- Modelled operating costs, net profit, and margin assumptions across 24 months with a single input sheet for scenario switching
- Analysed operational sales data to identify performance trends across customer segments, product lines, and regions
- Delivered a structured Excel workbook with separate tabs for revenue assumptions, scenario outputs, and a summary dashboard

## Key Skills Demonstrated
- Financial modelling: scenario analysis, revenue forecasting, cost modelling
- Excel: advanced formulas, dynamic scenario switching, dashboard design
- Data analysis: trend identification, customer and product segmentation
